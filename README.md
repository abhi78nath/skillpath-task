# Skillpath — Assignment

A responsive Framer landing page for Skillpath, a fictional learning platform.

## Live Website

[View the published Framer site](https://skillpath-abhi.framer.website/)

## Features

- Live course data fetched from the provided API
- Dynamic INR/USD pricing based on country code
- Loading, error, and empty states
- Retry functionality
- Graceful handling of country API failures
- Responsive 3/2/1 column course grid
- Refundable course badges
- Framer property controls for accent color and refundable badges

## API

Base URL:
https://syncsphere-hiv6.onrender.com

Endpoints:
- `/assignment/course-data`
- `/assignment/country-code`
